# SkinManager 1.1.4

**发布日期：2026-11-14**

SkinManager 1.1.4 为 Windows 上的 Codex 桌面版带来动画皮肤背景、更灵活的颜色编辑和更清晰的设置。你可以使用 GIF 背景、精细调色、配置登录 Windows 后的启动行为，并选择 SkinManager 的界面语言。

## 更新内容

- 导入、编辑、预览和导出时保留 GIF 动画；市场封面使用静态图片，下载后的皮肤保留动画。
- 使用色相环和饱和度、明度区域调整颜色，支持 HEX、RGB 和透明度；修改可实时预览、确认或取消。
- 按“常规／外观／兼容性”分类设置，并选择跟随系统、简体中文或 English。SkinManager 不会更改 Codex 的界面语言。
- 配置是否在登录 Windows 后启动管理器，以及是否启动调试版 Codex 并应用上次选择的皮肤。
- 登录市场账号后，可在软件“提出建议 → 反馈”或网站“我的投稿”旁的“反馈”入口提交标题和内容。邮件会附带账号信息和提交来源；软件内提交还会附上 SkinManager 版本，并使用账号邮箱作为回复地址。反馈暂不支持附件。
- 连续调整精细编辑选项时预览刷新更平滑，操作结束后会显示最终值。

## 安装与兼容性

- 支持 Windows x64 和 Microsoft Store 安装的 Codex 桌面版。
- 需要 Microsoft Edge WebView2 Runtime，用于界面预览和市场账号登录。
- 安装包不包含皮肤；可从市场下载，或导入自己的皮肤。
- 覆盖升级会保留皮肤库和偏好设置。升级后请重新应用皮肤。
- 安装包未进行代码签名。
